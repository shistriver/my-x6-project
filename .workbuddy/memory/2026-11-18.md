## bugfix：恢复草稿未重置缩放
- 现象：`GraphEditor.loadDraft()` 复用 `importJSON()`，后者收尾是 `zoomToFit()`（适配），不是重置 100%；切换地图路径在 UI 侧额外补了 `ed.transform('zoomTo')`，但两处恢复草稿（手动按钮 / 启动自动恢复）漏了 → 恢复后停在 zoomToFit 比例。
- 修法：在 `loadDraft()` 内 `importJSON()` 之后补 `this.transform('zoomTo')`，一处覆盖两条调用路径（符合"画布能力封装在类里"约定）。zoomTo 是视口操作不污染撤销栈。
- 验证：`npm run build`（vue-tsc -b + vite build）通过。

## 预览态画布背景改白色
- 之前编辑态/预览态共用 `GraphEditor.init()` 的 `background.color: '#F2F7FA'`，且 PreviewView 三处 CSS 也是 `#f2f7fa`（注释明确"不出现白色"）。
- 改法：`init()` 里 `color: preview ? '#FFFFFF' : '#F2F7FA'`（编辑态不变）；`PreviewView.vue` 的 `.preview-page`/`.preview-scroll`/`.preview-canvas` 三处 CSS 一并改 `#fff`。
- 关键点：X6 画布背景和预览页外围 CSS 必须一起改，否则出现"白画布 + 蓝灰外围"分界（预览里画布铺开尺寸=内容+留白，外围由 .preview-scroll 显示）。
- ⚠️ 漏网点：`loadJSONForPreview()` 里还有 `g.drawBackground({ color: '#F2F7FA' })`（fromJSON 后兜底重绘，会盖掉 init 的白色），必须一并改 `#FFFFFF` 才彻底干净。查背景色要全局 grep `F2F7FA|f2f7fa`，别只改 init 与 CSS。编辑态 init 里那处保留。
- 验证：`npm run build` 通过。
