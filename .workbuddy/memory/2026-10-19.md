## 修复 @antv/x6 报 "Failed to resolve import tslib"
- 现象：Vite 预构建 @antv/x6 后，运行时报 `Failed to resolve import "tslib"`（pnpm 严格 node_modules 不把 tslib 提升到项目根，X6 运行时要 import tslib）
- 根因：tslib 完全未安装（node_modules/.pnpm 里没有），@antv/x6 3.1.8 依赖 tslib 但未随 pnpm 拉下来
- 修复：`pnpm add tslib`（2.8.1，生成根级软链，Vite 可解析）；并 `rm -rf node_modules/.vite` 清掉旧预构建缓存重新优化
- 附带：HomeView.vue 原 `import { Graph }` 未使用（被注释），strict noUnusedLocals 报 TS6133；改为 onMounted 内真正实例化 Graph（带 grid + 示例节点），build 通过
- X6 打包后 HomeView chunk ~570KB（gzip 165KB），仅警告非报错
