## 空格平移：节点/组合上也要显示手型并能拖画布
- 根因：X6 Panning 只在 `blank:mousedown` / `node:unhandled:mousedown` 启动；落在节点/组合上时节点拖拽把 mousedown 吃掉 → 平移不触发。且节点 view 的 inline cursor 盖掉容器 `graph-pannable` 的 grab。
- 修复（`GraphEditor.ts` `bindSpaceRubberbandGuard` 扩展 + `bindPointerSelection` 放行 + `guides.css`）：
  - 空格按住：`spaceDown=true`；`selectionPlugin.disableRubberband()`；临时 `g.options.interacting=false` → 节点 mousedown 变 unhandled → Panning 接管整幅画布平移；容器加 `space-pan` 类。
  - `guides.css`：`.x6-graph.space-pan * { cursor: grab !important }` / `.space-pan-grabbing * { cursor: grabbing !important }`（!important 才能压住节点 inline cursor）。
  - 拖拽中（space+左键）切到 `space-pan-grabbing` 视觉。
  - `bindPointerSelection` 的 mousedown/mouseup 在 `spaceDown` 时直接 return，避免捕获阶段 stopPropagation 挡掉 Panning。
  - 松开/失焦/清理 `endSpacePan()` 幂等恢复：enableRubberband + 还原 `g.options.interacting=prevInteracting` + 移除类。
- 关键坑：keydown 自动重复会多次触发，用 `if (spaceDown) return` 防止 prevInteracting 被已置 false 的值覆盖。
- `pnpm run build` 通过。

## Ctrl+V 粘贴后需进入完整选中态（橙框+黑框）
- 根因：变换框（黑框）只靠 `bindPointerSelection` 手动 `syncTransformWidget()` 同步；Ctrl+V 由 X6 Clipboard 粘贴并 `g.select(top)` 触发 `selection:changed`，绕过自研逻辑 → 只有橙框、无黑框。
- 修复：在 `bindSelectionNormalize` 里加 `g.on('selection:changed', () => this.syncTransformWidget())`，统一在任意选区变化（粘贴/撤销重做/程序化选中/点选）时同步 Transform 变换框。单选→createWidget（黑框），多选/空选→clearWidgets（正确无黑框）。
- `pnpm run build` 通过。

  - `PropertyPanel.vue`：新增 `multiRoom` prop + `apply-room` emit；`multiRoomForm` 表单 + watch 回填 + `onRoomNumber` 受控数字；模板加「批量（房间）」区块（覆盖式，优先于样式批量）。
  - `HomeView.vue`：`multiRoom` ref + `getRoomStyleState()` + `handleApplyRoom` 接线。
- 行为：全选房间 → 房间批量面板；混入非房间 → 走原样式批量（房间不批量）；撤销整批一条。
- `pnpm run build` 通过。
