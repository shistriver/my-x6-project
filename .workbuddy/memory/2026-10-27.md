## 修复：预览页「矩形 / Circle 节点边框显示不完整（发虚、断断续续）」
- 现象：用户截图（外层红框 + 内部蓝矩形 + 绿圆），1px 描边的矩形/圆看起来边框缺一截、发虚；红色粗描边正常。
- 定位（pngjs 逐像素采样截图，统计「描边本色像素」覆盖率）：
  1. 蓝矩形左边覆盖率 0（单像素只有 ~50% 不透明度 = `[128,190,255]`），其余三边 = 1 → **描边落在半像素上被摊到两像素**；根因是节点几何本身带小数（x=256.4 之类），加上 `centerContent` 的平移量也可能带小数。
  2. 另有一条真实裁切：预画画布 `g.resize(内容 bbox)` + SVG `overflow:hidden`，描边有一半画在 bbox 外 → 最外层节点（截图里那个顶部浅色方块 / 红框）边缘被切掉。
- 修复（3 处）：
  - `GraphEditor.PREVIEW_PADDING = 8`；`resizeToContent()` 改为 `g.resize(ceil(area.w)+2*pad, ceil(area.h)+2*pad)` + `centerContent()` + `g.translate()` 取整。
  - 新增 `snapNodesToPixelGrid()`（预览专用，`loadJSONForPreview` 里 fromJSON 后调用）：按 `body/strokeWidth` 奇偶决定边缘落点——奇数描边落 `floor(x)+0.5`、偶数描边落 `round(x)`；跳过 `getAngle()!==0` 的旋转节点和 `getChildCount()>0` 的组合容器（容器隐形、位置交给成员各自对齐）。只改内存副本，不动 JSON/编辑态数据，误差 ≤0.5px。
  - `PreviewView.vue`：新增 `centerCanvas()`，用 JS 算整数 `marginLeft/marginTop` 代替 CSS `margin: 0 auto`（auto 居中在剩余空间为奇数时落在 .5px，整层内容跟着虚）；`readMetrics()` 里 `resizeToContent()` 之后调用；新增 `window resize` 监听重算居中（卸载时移除）。
- ⚠️ 关键坑：**平移量取整与节点半像素对齐必须配套**——描边落点 = 画布左偏移 + 平移量 + 节点坐标；若把平移量设为 `round+0.5`（早期做法）会正好抵消节点的 `.5`，边框又变成两条 50% 的线。最终方案：画布偏移/平移量取整 + 节点坐标按描边奇偶落 .5 / 整数。
- 验证（playwright-core + chromium-1234 + pngjs）：蓝矩形四边实色覆盖率 0 → 1，dpr=1/2 均 1；用户同布局（含小数坐标）四边全 1；内容超视口滚到最右，右侧描边不再被裁；`ROOM DETAILS` 弹框仍可点开（命中判定未受影响）；`vue-tsc -b` 通过，无 console 报错。
- 产出：项目根 `preview-border-fix.png`（修复前/后 6 倍放大对比图，蓝矩形左上角、下边、圆弧各一组）。

## 修复：组合（群组）复制后粘贴「不是组合」
- 现象：选中组合（容器或组内成员）复制、再粘贴，结果是空容器或散落成员，不再成组。
- 根因（读 X6 3.1.8 源码确认）：`ClipboardImpl.copy` → `model.cloneSubGraph(cells, options)`，而 `getSubGraph` **默认不递归子孙**（`options.deep` 才收集 `getDescendants`）。`cloneCells` 虽会重连父子，但前提是子节点进了 cloneMap——不带 `deep` 时子节点根本没进剪贴板。所以复制只带走被选中的那一个 cell，粘贴出来只剩孤容器 / 散落成员。
  - 验证（playwright + 本地 x6.min.js 真实 DOM）：旧行为 `copy([container])` 粘贴后 `pastedCount=1`（仅容器、0 子节点）；新行为 `copy([container], {deep:true})` 粘贴后 `pastedCount=3` 且容器 `getChildren().length=2`、子节点均在画布、`ok=true`。localStorage 与 in-memory 两种剪贴板模式都成立。
- 修复（`GraphEditor.ts`）：
  - 新增 `resolveCopyUnits()`：选中项里——若是组合容器本身 → 以它作单元（不向上爬，允许独立复制嵌套组）；若是成员/自由节点 → 上溯到最外层组合容器（自由节点无组祖先则保持自身）；去重。
  - `copySelected()` 改为 `g.copy(resolveCopyUnits(), { deep: true })`；键盘 `ctrl/cmd+c` 改为调 `copySelected()`。
  - `paste()` 改为粘贴后只选中「顶层单元」（父不在粘贴集内的 cell，即最外层容器 / 自由节点），不把成员逐个选中——否则拖拽成员（无 Alt）会只移该成员、把刚粘贴的组合拆散。键盘 `ctrl/cmd+v` 改为调 `paste()`。
  - 注：本项目的 `embedding.enabled:false`，父子关系纯靠 `addChild/unembed` 维护；粘贴时 `cloneCells` 已重连父子，无需 `findParent` 干预。
- 验证：`vue-tsc -b` 通过；浏览器端 deep 复制 + 粘贴成组结论已实测（见上），无 console 报错。
